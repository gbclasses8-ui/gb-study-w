GB STUDY Telegram Popup Fix

1. Backup your existing index.html first.
2. Replace it with this index.html in the same project folder.
3. Deploy the entire site folder again to Netlify.
4. Open the live site in a private/incognito tab to test the popup.
5. The Telegram popup uses your requested icon URL: https://res.cloudinary.com/koyp8kmo/image/upload/f_auto,q_auto/90
6. Popup is enabled by default. Admin can explicitly enable/disable it in Popup Settings and save.

Note: this popup is browser-side. Shared settings across all users require a backend/database.
